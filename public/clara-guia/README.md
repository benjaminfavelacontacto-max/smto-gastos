# Capturas de la guía "Cómo descargar tu estado de cuenta de Clara"

Estas imágenes se muestran dentro del botón **"Cómo descargar estado de cuenta"**
de la app (componente `ClaraGuideModal` en `src/App.jsx`).

Coloca aquí las 5 capturas de pantalla con EXACTAMENTE estos nombres:

| Archivo   | Paso del manual                                                        |
|-----------|-----------------------------------------------------------------------|
| `paso1.png` | Entrar a Clara (app.clara.cc / "Acceso Clientes")                   |
| `paso2.png` | Iniciar sesión ("Ingresa a Clara": correo o "Continuar con Google") |
| `paso3.png` | Abrir "Movimientos" en el menú lateral                              |
| `paso4.png` | Filtrar por fechas ("Añadir filtro" → "Fechas" → personalizadas)   |
| `paso5.png` | Descargar el CSV ("Descargar" → ".CSV")                             |

Notas:
- Formato recomendado: **PNG** (también sirve `.jpg`; si usas otra extensión,
  actualiza la ruta `img` del paso correspondiente en `CLARA_GUIDE_STEPS`).
- Si una imagen no existe, el paso se muestra igual solo con el texto (la app
  oculta el hueco de la imagen automáticamente).
